# Лабораторная работа 02: Классы и инкапсуляция

## Вариант
Программная инженерия (`ProjectTask`)

## Инварианты

### BankAccount (Подготовительная часть)
1. Начальный баланс не может быть отрицательным.
2. Пополнение возможно только на положительную сумму (строго больше нуля).
3. Списание возможно только на положительную сумму и не превышающую текущий баланс.
4. Нет публичного `setBalance` — баланс меняется только через методы `deposit` и `withdraw`.

### ProjectTask (Обязательное задание)
1. Идентификатор `id` не может быть `null` или пустой строкой (включая строки из пробелов).
2. Название `title` не может быть `null` или пустой строкой (включая строки из пробелов).
3. Оценка трудоемкости `estimatedHours` не может быть отрицательной.
4. Статус задачи меняется только через специальный метод `changeStatus`.
5. Оценка трудоемкости увеличивается только через метод `increaseEstimate` на строго положительное число.
6. Поля `id` и `title` объявлены как `final` и не могут быть изменены после создания объекта.

## Использование генеративного ИИ
Инструмент: **DeepSeek**.
Цель использования: объяснение методов классов и тестов. С помощью нейросети разбирался синтаксис Java, объяснялись значения ключевых слов (`private`, `final`, `void`, `enum`), разбиралось построчно уже написанное решение для лучшего понимания материала перед защитой лабораторной работы. Генерация готового кода не использовалась.
